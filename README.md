## 📌 專案簡介

本專案為 **2026 諾貝爾生理醫學獎：光遺傳學（Optogenetics）** 30 頁精華教學簡報的獨立有聲展示網頁。

### 🌟 核心功能
1. **左圖右文經典版面**：左側 66% 投影片原圖，右側 33% 精煉口語導讀講稿。
2. **Web Speech API 瀏覽器語音朗讀**：內建臺灣國語語音朗讀（支援 Google 國語 臺灣），可調語速與音調。
3. **無縫自動播放**：支援「朗讀完才換頁」與「固定秒數」兩種自動播放模式。
4. **全螢幕沉浸式放映（F 鍵）**：專為課堂投影與演講演示設計。
5. **膠卷縮圖與快速跳頁**：底部 Filmstrip 膠卷導覽與輸入頁碼跳頁。
